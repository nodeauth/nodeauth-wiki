# 应急恢复与灾后自救

在极端的灾难场景（如原服务器彻底损坏、数据库意外泄露或部署平台账号被封）下，NodeAuth 为您提供了多层次的资产保护伞。请根据您手头现有的“生存物资”选择最合适的恢复路径。

---

## 🚑 灾难恢复决策矩阵

| 手头现有的“生存物资” | 推荐恢复路径 | 核心原理 | 成功率 |
| :--- | :--- | :--- | :--- |
| **PDF (Recovery Kit) + 授权码 + 数据库** | **路径 A：环境级完美复活** | 填入原密钥与授权，原地复活所有数据 | 100% |
| **任意备份文件 (手动导出 / 自动定时)** | **路径 B：业务级数据导入** | 搭建新实例，将备份数据批量导回 | 100% |
| **手动导出的加密备份文件 + 离线解密脚本** | **路径 C：脱机人工读取** | 使用 Node.js 脚本直接查看明文 JSON | 100% |

---

## 📄 路径 A：环境级复活 (使用 Recovery Kit)
**场景**：您有原有的数据库（如 Cloudflare D1 或 Docker 的 `data/` 目录），但记不清原来的环境变量 `ENCRYPTION_KEY` 了。

1.  **准备环境**：在任何平台上重新部署一个新的 NodeAuth。
2.  **找回密钥与授权**：打开您的 **Recovery Kit PDF** 找到 `ENCRYPTION_KEY`；同时找回您的 `NODEAUTH_LICENSE`。
3.  **重建变量**：在新的部署环境中，手动将这两个关键变量填入。
4.  **连接数据**：确保新部署连接到了您之前的数据库。
5.  **瞬时复活**：登录新实例，由于密钥与授权逻辑锁定一致，系统能立即解密读取数据库里的原有账户。

> [!TIP]
> **关于 Recovery Kit 的生成与验证**：为了强制您妥善保存这份“生命线”，系统在初始化点击下载 PDF 后，要求您必须手动输入该 Key 的**最后 4 个字符**。只有验证通过，实例才算正式激活。

---

## 📂 路径 B：业务级恢复 (使用数据导入)
**场景**：您没有旧数据库，但拥有平时手动导出的备份文件，或者开启了“自动定时备份”。

1.  **准备环境**：建立一个全新的 NodeAuth 实例，配置全新的环境变量。
2.  **获取文件**：从您的 U 盘、邮箱或 Telegram/S3/网盘中下载最新的备份包。
3.  **执行导入**：
    *   前往“数据管理” -> “**数据导入**”。
    *   上传您的 `.json` 备份包（无论是自动定时备份，还是手动导出的均可）。
    *   如果是加密文件，输入您设置的**备份密码** / 导出密码。
4.  **合并成功**：您的资产将批量导入到当前新实例中，系统将自动对齐密钥并恢复验证码计算。

---

## 🛠️ 路径 C：离线手动解密 (使用解密脚本)
**场景**：极端的生存环境，无法立即搭建 NodeAuth 服务，但急需脱机查看某个账户的明文秘钥。

*   **前提**：拥有**前端手动导出**的加密 `.json` 备份文件 + 导出密码 + [scripts/decrypt_backup.js](https://github.com/nodeauth/nodeauth-worker/blob/main/scripts/decrypt_backup.js)。
*   **运行环境**：只需安装 [Node.js](https://nodejs.org/)。
*   **操作命令**：
    ```bash
    node decrypt_backup.js <备份文件名.json> <备份密码>
    ```
*   **结果**：解密后的数据将直接在控制台显示，并另存为 JSON 文件。由于您使用的是手动导出包，您可以直接在 `secret` 字段看到纯大写字母的明文秘钥，方便复制到其他验证器 App 应急使用。

> [!NOTE] 
> **如果您手里只有“自动定时备份”的文件怎么办？**
> 自动备份文件虽然也能用此脚本解开外壳，但由于底层安全保护，里面的秘钥依然是 `nodeauth:` 格式的密文，无法肉眼读取。遇到这种情况，请直接走 **[路径 B]**，导入系统即可瞬间解锁。

---

> [!CAUTION]
> **终极警告**：如果您既没有保存 Recovery Kit 导致 `ENCRYPTION_KEY` 丢失，也没有记录 `NODEAUTH_LICENSE`（且您的配置中使用了 `aes:` 加密加固），或者没有导出过任何备份文件，**那么全世界没有任何人（包括开发者）能帮您找回数据**。请务必将 Recovery Kit 打印后与护照或房产证放在一起。
