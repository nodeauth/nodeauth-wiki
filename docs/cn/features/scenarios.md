# 🎯 进阶使用

NodeAuth 部署完成后，为了获得最流畅且安全的使用体验，我们强烈建议您按照以下干货步骤，分别在您的 PC 端和移动端进行针对性配置。

## 💻 PC 端：打造极速无感填充

在电脑上，核心目标是通过浏览器扩展实现验证码的一键提取与填充。请按以下顺序配置：

1. **设置通行密钥 (Passkey)**
   * 在 NodeAuth 网页端，进入 `设置` -> `账号与安全` -> `通行密钥`。
   * 绑定您的 Windows Hello 或 macOS Touch ID。这将让您免输主密码，实现秒级生物识别登录。
2. **设置应用锁定 (PIN 码)**
   * 进入 `设置` -> `账号与安全` -> `应用锁定`。
   * 设置一个短 PIN 码，作为您的本地保险库的二次防护屏障。
3. **安装并配置浏览器扩展**
   * 前往扩展商店安装 NodeAuth 插件，输入您的主站地址完成安全配对。
   * **关键一步**：为使扩展发挥最大效能，请务必参考 [扩展最佳实践与场景配置](/cn/extension/usage#_8-最佳实践与场景配置)，根据您所处的环境（私人电脑 / 办公环境），配置好相应的自动锁定与剪贴板策略。

## 📱 移动端：原生 App 级操作体验

在手机上，核心目标是摆脱浏览器框的束缚，获得全屏沉浸和离线可用的原生体验。

1. **添加到桌面 (PWA)**
   * 在手机浏览器（iOS 推荐 Safari，Android 推荐 Chrome）中打开您的 NodeAuth 主站。
   * 点击浏览器的“分享”或“菜单”按钮，选择 **“添加到主屏幕”**。
   * 以后请**永远从桌面的独立图标启动** NodeAuth。
2. **设置通行密钥 (Passkey)**
   * 从桌面图标进入应用，在 `设置` -> `账号与安全` -> `通行密钥` 中。
   * 绑定您的 FaceID (iOS) 或指纹解锁 (Android)，实现开屏秒解。
3. **设置应用锁定 (PIN 码)**
   * 进入 `设置` -> `账号与安全` -> `应用锁定`。
   * 强烈建议开启，确保每次从后台切回 App 时都会触发验证，防范“借手机”时的偷窥风险。
4. **设置离线模式（可选）**
   * 进入 `设置` -> `安全控制` -> `离线模式`。
   * 开启后，即便在无网络信号的极端场景（如机房、飞机上），您依然能顺畅提取 2FA 验证码。
