# NodeAuth 浏览器扩展隐私政策
**最后更新日期：2026年8月4日**

### 1. 简介
NodeAuth 浏览器扩展程序旨在为您提供安全、便捷的 2FA/TOTP 令牌管理服务。您的隐私和数据安全是我们产品设计的核心。本隐私政策详细说明了我们在提供服务时，如何处理您的数据以及所需的系统权限。

### 2. 我们不收集的信息
NodeAuth 严格遵循 **零知识 (Zero-Knowledge)** 和 **本地优先 (Local-First)** 的架构原则。我们向您（以及应用商店审核团队）郑重承诺：
*   **不收集个人身份信息 (PII)**：我们绝不收集、存储或传输您的任何个人身份数据，例如姓名、电子邮件地址或电话号码。
*   **不追踪用户行为**：本扩展程序不包含任何分析 SDK、追踪像素或第三方监控代码。我们无法知晓您的浏览历史或具体点击行为。
*   **无云端备份**：您的主密钥 (Master Key)、TOTP 种子和保险库数据永远不会被发送或备份至 NodeAuth 的远程服务器。

### 3. 本地设备上的数据处理
为实现 2FA 管理功能，本扩展程序仅在您的设备本地处理必要的数据：
*   **加密保险库**：您的凭证数据均使用 AES-GCM 强加密算法进行加密，并仅安全地存储于浏览器的本地存储环境 (Local Storage) 中。
*   **易失性内存数据**：在建立加密通信隧道时所产生的临时密钥对，仅短暂驻留于浏览器的运行内存中。当浏览器关闭或会话超时后，该部分数据将被彻底销毁，绝不落盘。

### 4. 权限申请与合规用途说明
为确保扩展程序的正常运行并提供安全、无缝的服务体验，我们需要向浏览器申请以下权限。这些权限的作用域被严格限制在特定功能内：

*   **`storage` (存储)**：用于在设备本地持久化保存您的扩展设置状态，以及经过加密处理后的 2FA 凭证库。
*   **`tabs` & `activeTab` (标签页活动)**：用于读取当前活跃标签页的 URL 地址。此权限专门用于在本地比对匹配的凭证，并实时更新扩展图标上的角标 (Badge) 数量，以提示可用账号。
*   **`scripting` (脚本注入)**：用于在网页生命周期的早期动态注入安全公钥以建立端到端加密隧道；同时用于在匹配的 2FA 输入框旁，动态挂载不受外部样式污染的自动填充悬浮图标层。
*   **`alarms` (后台定时器)**：用于在后台注册可靠的计时任务。这是实现扩展程序在闲置指定时间后触发“自动锁定”和清理内存机制的关键依赖。
*   **`notifications` (系统通知)**：用于在您成功通过主站完成加密握手配对时，发送系统级通知以引导您设置本地安全解锁密码。
*   **`主机权限 (Host Permissions): <all_urls>`**：此为**可选权限**。仅当用户在设置中主动开启“验证码一键填充”高级功能时，扩展才会按需注册内容脚本以在全局网页中侦测验证码输入框。若用户未开启该功能，扩展不会请求任何全局主机权限。

### 5. 第三方交互与数据共享
我们承诺不会向任何第三方出售、交易或随意共享您的数据。唯一的例外是以下由用户主动控制的可选功能：

*   **服务图标获取 (可选功能)**：若您在设置中主动开启了“显示服务图标”功能，扩展程序会向公共图标库服务（如 Google, Bitwarden 等）请求对应账户域名的图标资源。
    *   **隐私披露**：开启此功能意味着请求时会将您的账户域名（如 `github.com`）发送给上述第三方服务商。
    *   **默认配置**：为保证最大程度的隐私，**该功能默认处于关闭状态**。在默认配置下，您的账户列表对任何第三方均处于物理隔绝状态。
