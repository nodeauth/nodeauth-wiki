# 🧩 使用指南

本指南将帮助您完成 NodeAuth 浏览器扩展的安装、授权配对以及掌握各项便捷的日常功能。

## 1. 安装扩展程序

您可以通过以下方式安装 NodeAuth 扩展：

### 推荐方式：官方商店安装

这是最便捷的安装方式，支持自动更新与云端验证。

*   👉 **[Chrome 应用商店](https://chromewebstore.google.com/detail/nodeauth/ejknfokfdojopelcbidgchnopeapnjgd)** (适用于 Chrome 浏览器)
*   👉 **[Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/bclpbakllopgjhelikbhccpjkgbmfpgd)** (适用于 Edge 浏览器)
*   👉 **[Firefox 扩展商店](https://addons.mozilla.org/zh-CN/firefox/addon/nodeauth/)** (适用于 Firefox 浏览器)

### 备选方式：手动安装（GitHub）

如果您无法访问浏览器扩展商店，可以从源代码仓库手动加载：

#### Chrome / Edge：

1.  前往 [NodeAuth 扩展仓库 Release 页面](https://github.com/nodeauth/nodeauth-browser-extension/releases) 下载最新的 `.zip` 文件并解压。
2.  在地址栏输入 `chrome://extensions/` 并回车。
3.  打开右上角的 **“开发者模式”**。
4.  点击“加载已解压的扩展程序”，选择解压后的目录。

#### Firefox：

1.  前往 [NodeAuth 扩展仓库 Release 页面](https://github.com/nodeauth/nodeauth-browser-extension/releases) 下载最新的 `.zip` 文件。
2.  在地址栏输入 `about:debugging` 并回车。
3.  点击左侧的 **“此 Firefox”** (This Firefox)。
4.  点击 **“临时载入附加组件...”**，选择下载的 `.zip` 文件。

> [!NOTE]
> 由于 Firefox 稳定版要求强制签名，手动加载的扩展在浏览器重启后会失效。如需永久使用，请优先使用官方商店安装。

## 2. 授权与配对

安装完成后，您需要将插件与您自己部署的 NodeAuth 实例建立安全连接。整个过程均由扩展端主动发起：

1.  **打开扩展程序**：点击浏览器右上角的 NodeAuth 图标。
2.  **输入实例地址**：在“连接您的 NodeAuth 实例”界面中，输入您的 NodeAuth PWA 地址（例如 `https://auth.example.com`）。
3.  **开始配对**：点击 **“开始配对”** 按钮。此时浏览器会自动打开您的实例网页进行身份验证。
4.  **授权成功**：验证通过后，网页顶部会弹出绿色提示：“浏览器扩展授权成功。请点击浏览器右上角的扩展图标继续设置密码。”（这代表加密隧道已经建立，扩展已安全获取您的数据）。

## 3. 设置本地 PIN 码

出于安全考虑，扩展程序拥有独立的本地锁定机制，不会将您的主密钥明文保存在硬盘上：

1.  **点击扩展**：授权成功后，再次点击浏览器右上角的 NodeAuth 图标。
2.  **设置密码**：界面会进入“设置解锁密码”环节。请输入一个 **6 位数字**的 PIN 码。
3.  **本地加密**：点击 **“锁定”**。该 PIN 码将作为本地保险库的二次加密钥匙，**NodeAuth 服务器绝对不会知道或存储该密码**。
4.  **日常解锁**：在随后的日常使用中，您只需要输入这个 PIN 码即可快速解锁扩展进行验证码填充。

## 4. 如何添加新账号

在日常使用中，当您在任何网站开启了两步验证（2FA）并看到二维码时，您无需掏出手机，即可直接在浏览器内完成添加。

1. **打开扩展**：点击浏览器右上角的 NodeAuth 图标。
2. **点击新增**：在顶部导航栏点击 **`+`** 号，进入新增账号页面。
3. **扫描当前网页 (推荐！)**：
   - 点击 **[ 扫描当前网页 ]** 按钮。
   - 插件会自动捕捉您当前网页上的二维码，瞬间提取其中的密钥和账号信息，省去所有繁杂的手工操作。
4. **其他添加方式**：
   - 如果网页没有二维码，您可以手动输入“服务名称”、“账号标识”和“密钥”。
   - 或者，您也可以使用 **[ 上传图片 ]** 功能，识别您保存在本地的二维码截图。

## 5. 体验一键无缝填充

这是 NodeAuth 最受喜爱的功能，它将彻底改变您的登录体验。

1. **进入登录页面**：在任何需要输入 6 位两步验证码的网页（例如 GitHub、Google 登录页面）。
2. **自动探测**：当您将鼠标点击或聚焦在验证码输入框时，输入框右侧或附近会自动悬浮一个 **NodeAuth 专属盾牌图标 🛡️**。
3. **一键填充**：
   - 点击该图标，会自动展开一个悬浮菜单，展示与当前网站匹配的账号列表（实时倒计时显示验证码）。
   - 点击您需要的账号，验证码就会被瞬间**自动填入**输入框中。

> [!TIP]
> 如果悬浮图标提示“🔒 请先点击扩展图标解锁 NodeAuth”，说明您的扩展当前处于自动锁定状态。只需点击浏览器右上角的扩展图标并输入 PIN 码即可解锁。

## 6. 个性化您的扩展设置

在插件的主界面底栏，点击 **“设置”**，您可以深度定制扩展的运行方式：

- **常规与外观**：
  - 自由切换界面语言（简体中文/English）。
  - 选择是否开启“服务图标”、“建议数量角标”以及“验证码一键填充”功能。
  - 更改列表布局（标准/紧凑）以及颜色主题（跟随系统/暗色/亮色）。
- **安全防护**：
  - 设置自动锁定延迟。若担心离开工位数据泄露，可设置为 3 分钟后锁定。
  - 开启剪贴板自动清除，防止复制的验证码被恶意软件截获。

## 7. 数据与实例管理

在设置页面的最底部，您可以看到“数据管理”区域：

- **当前实例地址**：这里显示了您当前绑定的 NodeAuth 主站地址（例如 `https://auth.yourdomain.com`）。
- **退出登录**：清除当前会话状态。
- **重置扩展**：如果您更换了服务器，或者遇到同步异常问题，点击这里将彻底抹除本地所有授权状态，使插件恢复至刚刚安装时的初始模样。

## 8. 最佳实践与场景配置

为了让 NodeAuth 浏览器扩展发挥最大效能并确保您的数据安全，我们为您准备了两套常见的最佳配置推荐。您可以根据自己所处的环境进行调整。

### 场景一：私人电脑的极致便捷

如果您是在家中、或者完全属于个人的电脑上使用 NodeAuth，**便捷性**通常是第一诉求。您可以这样配置：

**推荐设置路径**：点击底栏 `设置`
- ✅ **开启【验证码一键填充】**：享受在网页输入框直接点击盾牌图标填充的极速体验。
- ✅ **开启【建议数量角标】**：让浏览器右上角随时提示您当前网站可用的账号数。
- ✅ **开启【服务图标】**：让列表更加美观直观。
- ⏳ **【自动锁定延迟】设置为“直到浏览器关闭”**：这样您在浏览期间无需反复输入密码解锁。
- 📋 **【剪贴板自动清除】设置为“不清除”或“2分钟”**：在私人环境中，剪贴板驻留时间可以适当放长。

### 场景二：办公或公共环境的安全优先

如果您是在公司电脑、网吧或其他人可能接触到的设备上使用 NodeAuth，**安全性**必须放在首位，以防离开工位时数据被他人窃取。

**推荐设置路径**：点击底栏 `设置`
- 🔒 **【自动锁定延迟】设置为“3分钟”或“5分钟”**：这是最关键的一步。这样在您去倒水或参加短会时，扩展会自动上锁，保护您的验证码不被偷窥。
- 📋 **【剪贴板自动清除】设置为“30秒”**：强烈建议！公司电脑可能运行着大量未知软件或监控程序。开启此项后，复制验证码 30 秒后剪贴板会自动清空，防止凭证被恶意软件后台拦截。
- 🛑 **下班或离开前的好习惯**：如果您使用的是不固定的公共电脑，使用完毕后请进入设置底部点击**“退出登录”**或**“重置扩展”**，彻底清理本地授权。

### 外观与排版优化建议

- **当您拥有超过 10 个以上的账号时**：
  建议进入 `设置` -> `外观设置`，将 **列表布局** 改为 **“紧凑”**。这能让您在一屏内看到更多的账号，减少滚动操作。
- **关于主题切换**：
  默认的“跟随系统”能与 macOS/Windows 完美融合。如果您偏爱极客风格，可以强制将其设置为“暗色主题”。
